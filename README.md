# Sales Performance Dashboard

## Project Overview
This project analyzes sales data using MySQL and visualizes insights using Power BI dashboards. The goal is to understand sales performance across regions, categories, and time periods.

## Tools & Technologies
- MySQL
- Power BI
- SQL
- Excel
- GitHub

## Project Workflow
1. Created sales dataset and tables in MySQL.
2. Performed data cleaning and analysis using SQL queries.
3. Extracted insights from sales records.
4. Built interactive dashboards in Power BI.
5. Uploaded project files and documentation to GitHub.

## Key Insights
- Region-wise sales comparison
- Category-wise performance
- Monthly sales trends
- Identification of top-selling products

## Repository Files
- DATASET_SETUP.sql – SQL script to create tables
- ANALYSIS_QUERIES.sql – Queries used for analysis
- SALES_DASHBOARD.pbix – Power BI dashboard file
- Dashboard screenshots
